# ECORAA Design System

> **ECORAA Color Palette, Typography, Shape Language, and Material System**

## 1. Color System

| Color Name | Hex Code | Semantic Role / Usage |
|---|---|---|
| **Near White** | `#FAFAFA` | Main app background (`AppColors.background`) |
| **Springtime Rain** | `#EDEFF3` | Secondary surfaces, cards, containers (`AppColors.surface`) |
| **Wind Weaver** | `#C6D1D7` | Borders, dividers (`AppColors.border`) |
| **Wild Thistle** | `#9FA0B5` | Muted information, secondary text (`AppColors.textSecondary`) |
| **Soothing Sapphire** | `#2F7EDA` | Primary accent, interactive elements (`AppColors.primary`) |
| **Blackwater** | `#555663` | Primary text (`AppColors.textPrimary`) |

### Visual Balance
- 60% `#FAFAFA` (Background)
- 20% `#EDEFF3` (Surfaces / Panels)
- 8% `#C6D1D7` (Borders / Dividers)
- 5% `#555663` (Primary Text)
- 5% `#9FA0B5` (Muted Text)
- 2% `#2F7EDA` (Precision Sapphire Accent)

---

## 2. Typography

- **Primary Font:** `Inter` (UI, Headings, Body)
- **Terminal/Code Font:** `JetBrains Mono` (Logs, Console, Code blocks)

---

## 3. Shape Language & Spacing

- **Small controls:** 5–6px radius
- **Inputs:** 6px radius
- **Panels:** 8–12px radius
- **Floating surfaces:** 12–16px radius
- **Command surface:** 16–20px radius

---

## 4. Premium Glass Material System
Restrained translucent material used selectively for Command Palette, floating command interfaces, contextual panels, and dialogs.
- Subtle transparency
- Soft background blur
- Thin edge definition (`#C6D1D7` at low opacity)
- Extremely subtle shadows
- Neutral tint
